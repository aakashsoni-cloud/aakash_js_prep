#  Lazy Loading -> load only the component and media required at the initial load of the component 
###             -> it reduces the amount of data that need to be transfer
###             -> `React.lazy() in build function`
###             -> `result in faster page load`
###             -> `fallback function is called till the actual component is loading`

# Code Splitting -> use to split the code into small chunks and bundles.
###              -> reduces the bundle size and reduces the memory usage

# Tree Shaking  -> technique in modern bundle (webpack and parcel) to include only used code rest will be shaken off
###             -> reduces the bundle size and improve the performance.


# Minification -> removed unwanted code like white space and commented code 

# Compression

# use of CDN 

# Image Optimization

# Memoization -> memoize the function call and value of complex calculation.

# Server Side Rendering -> allow to pre-render the component on the server
###                    -> it reduces the amount of data that need to be transfer and processed on client side


# React Virtualization -> powerful technique for building high performance application 
###                    -> only render the items that need to be shown on the visible screen area
###                    -> it reduces the amount of data that need to be transfer and process.
###                    -> `used react-window and react-virtualized library`
###                    -> `faster page load and smother user experience`
